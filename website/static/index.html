05 Inside

How the renderer works

The renderer combines Go ports of Mermaid and browser code with bundled JavaScript for KaTeX and ZenUML and an original vector PDF writer. Tests compare renderer output with recorded results from upstream code. Some features and output paths have documented limits.

{{.Pipeline.SVG}}

The diagram code

The parsers, the databases and the renderers of mermaid {{.Version}}, for every diagram type, look and theme.

A small browser engine

DOM, CSS cascade, font matching, HarfBuzz shaping with the arithmetic of Blink, and the float geometry of Skia. It answers the size questions that mermaid asks a page.

Native layout engines

dagre, the layered algorithm of Eclipse ELK, cose-bilkent and fcose of cytoscape, swimlanes and tidy-tree. Each returns the bits of the original.

JavaScript semantics

Number formatting, object key order, the sort of V8, the order of promises, and Math functions with the results of Chromium.

06 Use it

One import, or one binary

Go
import mermaid "github.com/bvolpato/mermaid-go-renderer"

src := `flowchart LR
  A[Start] --> B{Done?}
  B -->|yes| C[Stop]`
svg, err := mermaid.Render(src)

png, err := mermaid.RenderPNG(src, mermaid.WithScale(2))
pdf, err := mermaid.RenderPDF(src, mermaid.WithPDFPaperFormat("A4"))
pdfFromSVG, err := mermaid.SVGToPDF(svg)

RenderPDF creates a PDF from Mermaid source. SVGToPDF converts an existing SVG. WithPDFPaperFormat selects a fixed page size. Without it, the page fits the diagram. PDF uses vector paths and TrueType fonts or Type 3 glyph subsets where possible. Unsupported fonts are outlined, and some contextual glyphs or ligatures may not extract as the original text. Drop shadows are flat silhouettes. Other filter graphs and image elements, including data URLs, are omitted. It needs Go 1.27.

Command line
go install github.com/bvolpato/mermaid-go-renderer/cmd/mmdg@latest

mmdg -i diagram.mmd -o diagram.svg
mmdg -i diagram.mmd -o diagram.png -s 2
mmdg -i diagram.mmd -e pdf -o diagram.pdf --pdf-paper-format A4
mmdg -i README.md -o README.out.md -a images

Use --pdf-paper-format to select a fixed page size. Without it, the PDF page fits the diagram. The -f flag remains accepted for compatibility.
