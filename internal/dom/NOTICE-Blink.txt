engine of Chromium. This file has the first comment of each of those Blink
files that has its license terms in the file. Each comment is copied without
changes from https://chromium.googlesource.com/chromium/src at the tag
156.0.8078.4, the version of the reference browser.

The Blink files that say "Use of this source code is governed by a BSD-style
license that can be found in the LICENSE file" are not in this file. Their
license is in ../font/LICENSE-Chromium.txt.

The text of the GNU Library General Public License, version 2, is in
../browser/LICENSE-LGPL-2.0.txt.

docs/LICENSE-AUDIT.md, findings F1 and F8, says what is open.
