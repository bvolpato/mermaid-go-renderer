One comment of imagesize.go names the class SVGImage of Blink, the layout
engine of Chromium. This file has the first comment of the Blink file of
that class. The comment is copied without changes from
https://chromium.googlesource.com/chromium/src at the tag 156.0.8078.4, the
version of the reference browser.

docs/LICENSE-AUDIT.md, finding F8, says what is open.
