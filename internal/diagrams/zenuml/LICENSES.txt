License notices for the ZenUML integration

The script tools/reference/gen-zenuml-bundle.mjs writes this file.
The source paths and hashes for zenuml.bundle.js.gz are in zenuml.bundle.json. That manifest also lists the six omitted AWS and Azure artwork files.
The bundle uses @zenuml/core source-map files, the antlr4 runtime, and marked. The script replaces pino, fs, and react with local stubs. esbuild is a build tool and is not included in the bundle.
